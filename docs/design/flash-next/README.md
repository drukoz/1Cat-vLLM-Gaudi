# Flash-Next on Gaudi program (RUK-2709)

Program documents for serving Qwen3.8-Flash-Next on Intel Gaudi2 with this plugin fork. The working copies live on the Paperclip task RUK-2709; these files are refreshed whenever the pull request is updated.

- [System map](system-map.md): what the plugin is, the model and its memory budget on Gaudi2, the node and the two software stacks, the user's reference measurements on Qwen3.8-27B, upstream state, program shape and research status. Version 0.8 (2026-11-17): section 17 lists the facts the plan rests on (facts 30-36 are M3's).
- [Reuse ledger](reuse-ledger.md): every capability the program needs and what already provides it, with the one vLLM engine pin (`8f816a3f`).
- [Plan](plan.md): target architecture (upstream model subclassed with three HPU seams), the CPU oracle (Hugging Face transformers on a tiny model), conventions, milestones M0–M5 with their subtasks, the qualification run sheet, the spike table and the checklist. Version 0.5 (2026-11-18): adds the fused GDN decode track, whose kernel is the GDN decode path. Version 0.4 (2026-11-17): M3 (MTP speculative decoding) is specified from checked facts; M4-M5 are outlines.
- [GDN core decode contract](gdn-core-decode.md): the fused GDN decode kernel (track RUK-2812): op schema, state layouts, semantics, padding rules, flags, and the phase 2 (draft verification) contract.
- [TPC simulator on the Mac](tpcsim.md): the amd64 container with the Gaudi TPC compiler and the Gaudi2 simulator, used to compile and check the kernels without a card.
- Run sheets (`run-sheets/`, from M0): the exact commands, expected log lines and results tables the user executes on the node, since no agent has hardware access. [Template](run-sheets/README.md) and [qualification sheet stages 1–2](run-sheets/qualification.md) (build and native compile, tiny-model bring-up, real-checkpoint TP8 BF16 bring-up; stages 3–4 filled by M1 and M2, stage 3e by M3, stage 1b and row 3f by the fused GDN track, stages 5–6 by M4).
